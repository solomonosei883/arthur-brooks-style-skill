# Animation library catalog

280 reference animations. Their media lives in your own study folder (e.g. `~/arthurcbrooks-study/animations/`, not included in this repo). Each folder holds `clip.mp4` (segment with audio), `still.png` (keyframe), `strip.jpg` (every frame, or every 2nd–4th frame for long clips, labelled frame number + ms, keyframe outlined) and `notes.md` (category, source frames, words, keyframe, description, timing table with lag vs voice, motion, design, recipe). Machine-readable: `animations/index.json`.

To study a move: read `references/library/<ID>.md` (bundled with the skill: the same notes as each folder's `notes.md`). On the user's Mac, also open that folder's `strip.jpg`, and play `clip.mp4` when you need the motion feel or the audio sync.
